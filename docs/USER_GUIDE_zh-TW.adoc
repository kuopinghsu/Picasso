Picasso 是一套在你自己的電腦上執行的相片圖庫、檢視器與編輯器，承襲 Picasa 的精神。它會監看你指定的資料夾，依日期排列其中的相片與影片，編輯相片時也不會改動檔案。Picasso 不會上傳任何資料：它只會從網路下載地圖圖磚，以及在你允許時查詢最新的版本號碼。

本指南依照實際使用的順序介紹 Picasso。若要從原始碼建置 Picasso，請參閱 link:https://github.com/kuopinghsu/picasso/blob/main/README_zh-TW.md[README]。

NOTE: 本指南的快速鍵以 kbd:[Ctrl] 表示。在 Mac 上請改用 kbd:[⌘]，例如 kbd:[Ctrl+A] 就是 kbd:[⌘+A]。

[#install]
== 安裝 Picasso

請從 link:https://github.com/kuopinghsu/picasso/releases/latest[最新發行版本] 下載 Picasso。Intel 與 AMD 處理器請使用 `x64` 套件，64 位元 Arm 處理器請使用 `arm64` 套件。

Windows::
下載 `.exe` 後直接執行即可，不必安裝。`.zip` 內含同樣的程式，另附說明文件與授權條款。

macOS::
打開 `.dmg`，把 Picasso 拖到「應用程式」資料夾。除非發行說明表示應用程式已經過 Apple 公證，否則第一次啟動會被系統阻擋。請到「系統設定 → 隱私權與安全性」按一下「強制打開」，再確認一次。在 macOS 14 及更舊的版本上，也可以按住 Control 鍵並按一下 Picasso，再選擇「打開」。

Linux::
`.AppImage` 不必安裝，就能在大多數發行版上執行：
+
[source,bash]
----
chmod +x picasso-<version>-linux-x64.AppImage
./picasso-<version>-linux-x64.AppImage
----
+
在 Debian 與 Ubuntu 上，執行 `sudo apt install ./picasso-<version>-linux-x64.deb` 即可安裝 Picasso 及其選單項目。`.tar.gz` 的用法，以及沒有 FUSE 時該怎麼做，請見 README。

[#ffmpeg]
=== 播放影片需要 FFmpeg

Picasso 使用 link:https://ffmpeg.org[FFmpeg] 播放影片。沒有安裝時，相片照常可用，影片則會先略過，等安裝 FFmpeg 後再加入。

* Windows：`winget install Gyan.FFmpeg`
* macOS：`brew install ffmpeg`
* Linux：`sudo apt install ffmpeg`，或使用你的發行版提供的套件

在 Windows 與 Linux 上，如果無法安裝軟體，可以把 `ffmpeg` 與 `ffprobe` 放在 Picasso 或 AppImage 所在的資料夾中。

== 第一次啟動

第一次啟動時，Picasso 會加入你的「圖片」資料夾，並在背景讀取。狀態列會顯示進度，找到的相片會依日期陸續出現。掃描期間也可以照常使用 Picasso。

若要加入其他資料夾，請按一下右上角的「+  匯入」，或把資料夾拖進視窗。Picasso 也會一併加入所有子資料夾。

Picasso 絕不會搬移、重新命名或改寫你的相片。星號、說明、相簿、地點、修正過的日期與編輯，都存放在 Picasso 自己的圖庫中，只有「移至垃圾桶」會變動相片檔案。

== 圖庫視窗

視窗分為四個部分：

側邊欄::
「圖庫」會顯示所有相片。下方依序是「已加星號的相片」、「地點」、「統計資料」、「旅行地圖」與「重複的檔案」，接著是你的相簿與資料夾樹狀圖。每個資料夾都會顯示其中的相片數量。

頂端列與工具列::
頂端列有搜尋欄位。縮圖上方有標題與相片數量、排序方式，以及處理所選相片的按鈕。

縮圖::
縮圖依拍攝日期分組排列。依日期排序時，縮圖旁會有一條列出年份的時間軸，並展開目前所在年份的各個月份，按一下即可跳到該處。拖曳捲軸時，會顯示目前位置的日期。

狀態列::
顯示掃描進度、內含所選相片的「相片匣」，以及有無法讀取的檔案時，開啟清單的連結。

右上角依序是「+  匯入」、「重新整理」、「投影片播放」、開啟「說明與快速鍵」的「?」，以及開啟「設定」的齒輪。按一下左上角的標誌，會開啟顯示版本的「關於 Picasso」。

按 kbd:[I] 可以顯示或隱藏縮圖旁的資訊與地圖面板，其中會顯示所選相片的相機資訊與拍攝地點。

== 尋找相片

=== 排序

工具列上的排序選單提供：

* 「依日期排序」（由新到舊），或「依日期排序（最舊優先）」
* 「依名稱排序」
* 「依名稱排序，已編輯」，只顯示你編輯過的相片

=== 搜尋

在視窗頂端的「搜尋相片」欄位中輸入文字，就會找出符合每個字詞的相片。比對範圍包括檔名、資料夾路徑、說明、相機型號、鏡頭與相簿名稱。

輸入日期，可以找出當時拍攝的相片：`2019` 會找出那一年， `2019-05` 那個月， `2019-05-17` 那一天。也可以寫成 `2019/05` 或 `2019.05` 。日期與字詞可以一起使用，例如 `2019-05 beach` 會找出 2019 年 5 月拍攝、且與「beach」相符的相片。

搜尋字詞可以進一步縮小結果：

* `type:video`、`type:photo` 或 `type:raw`，或 `type:jpg`、`type:nef` 這類單一格式
* `gps:yes` 或 `gps:no`，找出有或沒有地圖位置的相片
* `is:edited` 或 `is:starred`
* `camera:` 或 `lens:` 加上部分名稱，例如 `lens:50mm`
* `focal:35`，或 `focal:24-70`、`focal:200-` 這類範圍，單位為公釐
* `mp:12`，或 `mp:20-`、`mp:-8` 這類範圍，單位為百萬像素
* 以 `-` 開頭的字詞會排除它會找到的相片，例如 `beach -type:video` 會找出與「beach」相符的相片，但不含影片

除了編輯器以外，在任何畫面按 kbd:[Ctrl+F] 都可跳到搜尋框；若檢視器開著，會先關閉它。

在搜尋框中按一下，會列出你最近的十筆搜尋；開始輸入後，只列出包含所輸入文字的搜尋。按一下其中一筆即可再次搜尋，也可以用 kbd:[↑] 與 kbd:[↓] 選擇後按 kbd:[Enter]。按 kbd:[Enter] 或點選搜尋框以外的地方時，該次搜尋就會加入清單。清單儲存在 `settings.json` 中，下次啟動 Picasso 時仍然保留；清單底部的「清除最近的搜尋」可清空清單。

=== 選取

* 按一下相片即可選取。
* 按住 kbd:[Ctrl] 再按一下，可以把相片加入選取範圍，或從中移除。
* 按住 kbd:[Shift] 再按一下，會選取上一次按的相片到這一張之間的所有相片。
* 按 kbd:[Ctrl+A] 會選取所有相片。
* 方向鍵可以移動選取範圍。
* 工具列上的 ★ 按鈕會選取畫面中已加星號的相片。

選取的相片會出現在狀態列的「相片匣」中，按「清除」即可清空。

== 整理相片

大部分指令都在三個地方：縮圖上方的工具列、「相片匣」，以及在縮圖上按右鍵開啟的選單。這些指令會套用到所有選取的相片。

=== 星號

按 kbd:[S] 或工具列上的星號，即可為所選相片加上星號；再按一次則移除星號。側邊欄的「已加星號的相片」會列出全部。

=== 說明

開啟相片，按 kbd:[I] 開啟詳細資料面板，在「說明」欄位中輸入文字即可。搜尋時也會比對說明。

=== 相簿

相簿可以把不同資料夾的相片集合在一起，而不必搬移檔案。

* 若要建立相簿，請選取相片，再從工具列的「加入相簿」中選擇「新增相簿…」。
* 若要把相片加入相簿，請選取相片，再從「加入相簿」中選擇該相簿。
* 在相簿中，「從相簿中移除」會把所選相片移出相簿，檔案本身不受影響。
* 若要刪除相簿，請在側邊欄的相簿上按右鍵，選擇「刪除相簿」。相片仍會留在圖庫中。

=== 旋轉

按 kbd:[R] 會把所選相片順時針旋轉，按 kbd:[Shift+R] 則逆時針旋轉。旋轉設定存放在圖庫中，不會改寫檔案。

=== 修正拍攝日期

相機時間設定錯誤，或是翻拍的舊相片，可以選取這些相片，在其中一張上按右鍵，選擇「調整日期…」。

* 「平移」會把所有選取的相片移動指定的天數、小時與分鐘。
* 「設為」會把最早的一張設為指定的日期與時間，其他相片隨之移動。
* 「使用檔案中的日期」會取消你的修改。

新日期存放在圖庫中，重新掃描後依然有效，檔案本身則不會變更。

=== 把相片移至垃圾桶

按 kbd:[Delete]，或按「相片匣」中的「刪除」，即可把所選相片移至系統垃圾桶。除非你在「設定 → 一般」中關閉了詢問，否則 Picasso 會先確認。

在 Windows 與 Linux 上，狀態列會在兩分鐘內提供「復原」，把檔案放回原處。在 Mac 上，請從 Finder 的垃圾桶還原檔案。無論哪種方式，只要相片在 90 天內回來，它的星號、說明、相簿與編輯都會回來。

=== 重新命名檔案

在資料夾樹狀圖中的資料夾上按右鍵，選擇「重新命名檔案…」，即可依照樣式重新命名其中的相片與影片，效果與 `+exiftool "-filename<${DateTimeOriginal}%-03c.%le" -d %Y.%m.%d-%Hh%Mm%Ss .+` 相同。
只會重新命名直接位於該資料夾中的檔案，不包含子資料夾中的檔案。

在「新名稱」中輸入樣式，或按一下下方的關鍵字加入：

* `+${DateTimeOriginal}+` 是拍攝日期，`+${FileModifyDate}+` 是檔案最後修改的日期，兩者都依「日期格式」寫出
* `+${Model}+` 是相機，名稱與資訊面板中相同
* `%f` 是不含副檔名的原本檔名
* `%-03c` 是只在名稱已被使用時才加上的編號，因此同一秒拍攝的相片會依序加上 `-001`、`-002` 等
* `%le` 是小寫的副檔名，`%e` 則是原樣的副檔名

日期格式中，`%Y` 代表年、`%m` 代表月、`%d` 代表日、`%H` 代表時、`%M` 代表分、`%S` 代表秒，因此 `%Y.%m.%d-%Hh%Mm%Ss` 會寫成 `2023.05.17-14h30m05s`。
拍攝日期就是 Picasso 顯示的日期，包括你修正過的日期；影片的時間則換算為當地時間，與 exiftool 的 `-api QuickTimeUTC=1` 相同。
檔案本身沒有日期時，使用的是檔案最後修改的日期；若要改用其他日期，請先用「調整日期…」設定。

「時間偏移」可在相機時鐘不準時移動名稱中的日期，與 exiftool 的 `-globalTimeShift` 相同：`+1:30` 是晚一個半小時，`-0:00:10` 是早十秒，`+2 0:00` 是晚兩天。
它只影響名稱，也不會保留到下次；若要一併修正 Picasso 顯示的日期，請改用「調整日期…」。

清單會在變更任何檔案之前，先顯示每個檔案的新名稱。
無法使用的名稱（例如少了檔案的副檔名，或含有 `:`）會以紅色顯示，該檔案會保留原本的名稱。
已經符合樣式的檔案會保留名稱，所以重新命名兩次不會有任何變化。
「重新命名」會一次重新命名所有檔案；只要有一個檔案無法重新命名，就全部維持不變。相片的星號、說明、相簿、編輯與地點都會保留。
與相片搭配的 `.xmp`、`.aae` 與 `.thm` 檔案會一起重新命名，因此 `DSC0001.xmp` 與 `DSC0001.JPG.xmp` 會跟著 `DSC0001.JPG` 改名。

每次重新命名都會記錄在資料夾中的 `.picasso-renames.json` 檔案裡，包含每個檔案的舊名稱與新名稱。
「復原」會改回清單中最近一次重新命名之前的名稱，即使 Picasso 關閉過也可以；再按一次就再往前復原一次。
如果先前的名稱已被其他檔案使用（例如相機新匯入的 `DSC0001.JPG`），該檔案會維持目前的名稱，並留在清單中待日後復原。

== 檢視相片與影片

在相片上按兩下，或選取相片後按 kbd:[Enter]，即可開啟檢視器。

* kbd:[←] 與 kbd:[→] 切換上一張與下一張相片， kbd:[Home] 與 kbd:[End] 跳到第一張與最後一張。
* 可以用滑鼠滾輪、按住 kbd:[Ctrl] 捲動滾輪、觸控板雙指縮放，或按 kbd:[+] 與 kbd:[−] 縮放，拖曳即可平移。
* kbd:[0] 讓相片符合視窗大小， kbd:[1] 以實際大小顯示每一個像素。
* 底部的縮圖列會顯示前後的相片，按一下即可切換。
* kbd:[I] 會開啟詳細資料面板，顯示相機設定、色階分佈圖、「說明」、「在資料夾中顯示」與「在地圖上顯示」。
* kbd:[F11] 切換全螢幕， kbd:[Esc] 返回圖庫。

檢視器的工具列上也有在淺色與深色主題之間切換的按鈕。

=== 投影片播放

按一下「投影片播放」，或在檢視器中按 kbd:[Space]，即可從所選的相片開始播放。kbd:[Space] 暫停與繼續， kbd:[Esc] 結束投影片播放。每張相片顯示的時間可在「設定 → 一般」中設定。相片會淡入淡出切換到下一張。工具列上的「隨機播放」或 kbd:[Shift+S] 會以隨機順序播放相片，每張都播過一次後才會重複。

=== 複製相片或在其他應用程式中開啟

* kbd:[Ctrl+C] 或「複製相片」會把套用編輯後的相片（最長 4096 像素）放到剪貼簿，可貼到其他應用程式。
* 「複製路徑」會複製每張選取相片的完整路徑，一行一個。
* 「以預設應用程式開啟」會用系統預設的應用程式開啟檔案。

這些指令都在縮圖的右鍵選單與檢視器的「···」選單中。

=== 影片

影片在縮圖中會顯示播放標記與長度。在檢視器中， kbd:[Space] 播放與暫停， kbd:[M] 靜音。影片無法編輯。

== 編輯相片

開啟相片後按 kbd:[E]，或按一下「編輯」，編輯器就會取代詳細資料面板。編輯絕不會改動檔案。每次修改都是儲存在圖庫中的一個步驟，相片則由原始檔案加上這些步驟即時產生。編輯過的相片，縮圖上會有一個小小的滑桿標記；按一下即可再次編輯。

image::editor.png[編輯器]

編輯器最上方有四個工具：「調整」、「裁切」、「變形」與「遮罩」。下方有復原與重做、內含「全部復原」、「全部重做」、「全部重設」、「複製」與「貼上」的 ··· 選單、即時色階分佈圖，以及「修改前」、「並排」、「分割」按鈕與剪裁警告按鈕。

=== 調整

「調整」工具中的滑桿分成以下區塊：

[cols="1,3"]
|===
| 區塊 | 用途

| 描述檔 | 作為各滑桿調整前的基礎風格：色彩、中性、鮮豔、風景、人像或單色
| 預設集 | 25 種內建風格，可用「總量」滑桿調整套用程度；也能把自己的設定儲存為預設集重複使用
| 變形 | 不必離開「調整」，就能旋轉、傾斜、轉 90° 與翻轉
| 光線 | 曝光度、對比、亮部、陰影、白色與黑色
| 色調曲線 | 分成四個區域的曲線，以及 RGB、紅、綠、藍的點曲線
| HDR | 在單張相片中提亮暗部、找回亮部細節
| 色彩 | 白平衡（可用滴管點選應為中性灰的位置）、細節飽和度與飽和度
| 混色器 | 八種顏色各自的色相、飽和度與明亮度
| 色彩分級 | 陰影、中間調、亮部與整張相片的色輪
| 效果 | 紋理、清晰度、去朦朧、暈映與顆粒
| 細節 | 銳利化與雜訊減少
| 黑白 | 轉為單色，並以八種顏色調整灰階明暗
| 步驟記錄 | 從第一步起的每一個步驟
|===

在滑桿名稱上按兩下，即可歸零。想快速開始時，「光線」中的「自動色調」會平衡曝光度與對比，「色彩」中的「自動」則會設定白平衡。

=== 裁切

按 kbd:[C] 開啟「裁切」工具。拖曳裁切框的邊緣或角落，或在框內拖曳來移動位置。選擇長寬比，或選「自由」；按 ⇄ 可切換直式與橫式。「拉直」滑桿會旋轉相片，並讓裁切框維持在相片範圍內。完成後按 kbd:[Enter]、 kbd:[Esc] 或「完成」。

=== 變形

按 kbd:[T] 開啟「變形」工具，它會在每個角落和每一邊的中點各放一個控制點。

* 拖曳角落可以只移動該角，例如讓傾斜的建築站直。
* 拖曳邊的中點可以歪斜或拉伸相片。
* 在外框內拖曳可移動相片，在外框外拖曳則可旋轉相片。

細框標出最後會保留的範圍。「重設角落」會把四個角落還原。

=== 遮罩

「遮罩」工具可以只調整相片的一部分。按「＋ 線性漸層」新增漸層遮罩（例如用於天空），或按「＋ 放射狀漸層」新增圓形遮罩。在相片上拖曳遮罩的控制點，再設定「羽化」、「反轉」，以及這個遮罩專屬的曝光度、對比、色彩、清晰度與去朦朧。勾選核取方塊後，會以紅色顯示遮罩的範圍。

=== 復原、步驟記錄與比較

* kbd:[Ctrl+Z] 復原一個步驟， kbd:[Ctrl+Y] 或 kbd:[Ctrl+Shift+Z] 重做。
* 位於「調整」最後的「步驟記錄」會列出每個步驟，按一下即可回到該步驟。
* 「修改前」（ kbd:[\ ] ）顯示原始相片，「並排」（ kbd:[Y] ）同時顯示修改前後，「分割」（ kbd:[Shift+Y] ）則在兩者之間放一條分隔線。
* 剪裁警告按鈕（ kbd:[J] ）會以紅色標出過曝的亮部、以藍色標出欠曝的暗部。
* ··· 選單中的「全部重設」會從原始相片重新開始，這同樣是一個可以復原的步驟。

=== 把編輯套用到其他相片

「複製」（ kbd:[Ctrl+Shift+C] ）會複製相片的設定，「貼上」（ kbd:[Ctrl+Shift+V] ）則套用到另一張相片。在圖庫中，右鍵選單的「貼上設定」會套用到所有選取的相片。裁切與「變形」設定只屬於單張相片，因此不會複製。

=== 匯出

編輯只存在 Picasso 中，匯出後才會成為檔案。

* 在編輯器中，「匯出…」會把正在編輯的相片另存為新檔案，預設檔名為 `name-edited.jpg` 。
* 若要匯出多張相片，請選取它們，再按「相片匣」中的「匯出…」，或在其中一張上按右鍵。選擇「資料夾」、「格式」（JPEG、PNG 或 TIFF）、「大小」（「原始大小」或長邊 4096、2048、1600、1080 像素），以及 JPEG 的「品質」。

匯出的檔案沿用原本的檔名並換上新的副檔名；檔名已存在時會自動加上編號，絕不覆寫任何檔案。影片不會匯出。狀態列會顯示進度與「停止」按鈕，完成後則顯示「開啟資料夾」。

== 地圖與地點

地圖需要連上網路。Picasso 會保留顯示過的地圖圖磚，因此看過的地方之後也能離線瀏覽。

=== 地點

image::places.png[地點]

側邊欄的「地點」會在地圖上標出所有含位置資訊的相片。拖曳可移動地圖，用滾輪或雙指縮放即可放大縮小。距離相近的相片會合併成一個標有數量的圖釘。把指標移到圖釘上，會出現一張列出相片的資訊卡：按一下相片即可開啟，也可以按「選取這些相片」或「放大」。按一下含多張相片的圖釘會放大到這些相片；如果這些相片是在同一個地點拍攝的，則會選取它們。在單張相片的圖釘上按兩下則會開啟該相片。「在 OpenStreetMap 中開啟」會在網頁瀏覽器中開啟同樣的範圍。

搜尋時地圖上只會留下符合的相片並將它們納入畫面，工具列上的「僅限已加星號」則只留下已加星號的相片。在「圖庫」輸入的搜尋，開啟「地點」時會保留，回到「圖庫」時也會保留，方便查看搜尋結果的拍攝地點後再回到結果。「在地圖上顯示」會清除搜尋並關閉「僅限已加星號」，確保你選的相片一定會出現在地圖上。

在相片上按「在地圖上顯示」，會開啟「地點」並移到該相片的位置。

=== 手動標記地點

沒有 GPS 資訊的相片：

. 在圖庫中選取相片。
. 開啟「地點」，選取範圍會保留。
. 按一下「標記地點」，再在地圖上按一下拍攝的位置。

「清除地點標記」會移除你放置的圖釘。相機 GPS 記錄的位置絕不會被變更。

=== GPS 軌跡

Picasso 會讀取資料夾中的 `.gpx` 與 `.kml` 檔案，以及 Polarsteps 匯出位置記錄的 `.json` 檔案（例如 `locations.json`），以彩色路線繪製在相片圖釘下方。把指標移到軌跡上，會顯示名稱、開始時間、距離與經過時間；按兩下軌跡即可放大顯示整條軌跡。按一下軌跡會選取沿途拍攝的相片：距離路線 300 公尺以內，且若軌跡有時間，拍攝時間在其前後 14 小時以內，因此相機時鐘設在其他時區也能對上。在側邊面板的軌跡上按右鍵，選擇「選取沿途拍攝的相片」也有同樣效果。按「地點」工具列上的「軌跡」可以隱藏路線。

資料夾中的軌跡也會列在圖庫格狀檢視的最上方「GPS 軌跡檔」之下，每條軌跡都會顯示路線形狀、格式與距離。

=== 編輯軌跡

image::trackedit.png[軌跡編輯器]

在圖庫格狀檢視中按一下軌跡，或在格狀檢視或「地點」中的軌跡上按右鍵並選擇「編輯軌跡」，即可開啟軌跡編輯器。編輯器會像 GPXViewer 一樣整理軌跡：捨棄以不可能的速度到達的點、移除線條不需要的點、把停留期間的點合併為一個，也可以用曲線補上長距離空缺；飛行路線則保持原樣。

地圖會填滿整個視窗。工具浮在地圖左上角，上方有「整條軌跡」、「起點」、「終點」與「最高點」按鈕，縮放控制則在右上角。右側面板會顯示「統計資料」、「海拔」剖面圖、選取的「點」，以及「整理」設定。沒有海拔資料的軌跡（例如來自 Polarsteps 的軌跡）會以一段說明取代剖面圖；每個點的海拔都是 0 公尺時，也視為沒有海拔資料。按一下其中的「查詢海拔」，即可從免費的 https://github.com/tilezen/joerd/blob/master/docs/attribution.md[AWS Terrain Tiles] 填入海拔：只會傳送軌跡沿途地圖圖磚的編號，和顯示地圖時一樣，各個點不會離開這台電腦。若仍有點查不到海拔，這個按鈕會保留，方便再試一次；按 kbd:[Ctrl+Z] 即可移除這些海拔。把指標移到剖面圖上，地圖上會標出該處；按一下或沿著剖面圖拖曳即可移到那裡。把指標移到地圖上的點，剖面圖上也會標出它。

* 拖曳點即可移動，按一下線條即可新增點。
* 在點上按右鍵並選擇「移除點」，或選取點後按地圖下方列中的「移除」。
* 按 kbd:[R] 後拖曳出方框圈選多個點，或按住 kbd:[Ctrl] 逐一點選；按 kbd:[V] 則回到移動點。
* 按 kbd:[←] 與 kbd:[→] 可逐一切換點。
* kbd:[Ctrl+Z] 復原，kbd:[Ctrl+Y] 重做。
* kbd:[1] 到 kbd:[4] 分別顯示整條軌跡、起點、終點與最高點。
* 「顯示原始軌跡」會顯示整理前讀入的原始軌跡。

長於「飛行距離」或快於「飛行速度」的移動會以虛線的飛行路線顯示，停留超過「停留」時間的地方則會標上圓圈。變更設定後按「再次整理」即可重新整理軌跡；「預設值」會恢復 GPXViewer 的數值。你變更的設定會成為下一條軌跡的預設值。

檔案本身絕不會被變更，編輯器也不會儲存覆蓋它。「另存為 GPX…」與「另存為 KML…」會在軌跡旁儲存一份副本，預設檔名加上 `-optimized` ；按 kbd:[Ctrl+S] 則以軌跡原本的格式儲存。副本會保留整理設定與每次停留的時間長度，因此會按儲存時的樣子開啟，不會重新整理；由 GPXViewer 儲存的軌跡也一樣。復原到整理之前時，整理設定也會一併還原。按 kbd:[Esc] 或「返回」會關閉編輯器，若有尚未儲存的編輯，會先詢問。尚未儲存的編輯會在每次變更後幾秒內保留下來，因此若 Picasso 結束或意外停止，下次啟動時會詢問是否還原。

=== 依 GPS 軌跡標記地點

如果拍攝時帶著 GPS 記錄器或用手機程式記錄了軌跡，Picasso 可以比對相片與軌跡的時間，自動標記地點：

. 在資料夾樹狀圖中的資料夾上按右鍵，選擇「依 GPS 軌跡標記地點…」。
. 選擇「GPS 軌跡」檔案（ `.gpx` 、 `.kml` 或 `.kmz` ），並確認「資料夾」。
. 設定「相機時區」：相機時鐘與 UTC 的時差，例如 `+01:00` 。相機通常記錄當地時間，而不記錄時區。
. 按一下「標記地點」。

已有相機 GPS 位置或你放置的圖釘的相片，會保留原本的位置。Picasso 會把地點寫入圖庫，以及資料夾中的 `.picasso-geotags.json` 檔案，絕不寫入相片本身。

在終端機中也能這麼做，加上 `--dry-run` 只會顯示結果，不會儲存任何變更：

[source,bash]
----
picasso geotag track.gpx ~/Pictures/Trip --offset +01:00 --dry-run
----

其中的 `picasso` 代表 Picasso 程式：Windows 上是你下載的 `.exe` ，Mac 上是 `/Applications/Picasso.app/Contents/MacOS/picasso` ，也可以是 `.AppImage` 檔案，安裝 `.deb` 後則直接使用 `picasso` 。

== 統計資料

image::statistics.png[統計資料]

側邊欄的「統計資料」以數字呈現你的圖庫：每年與每月的相片數、拍照的天數、你的相機、鏡頭與焦距，以及有多少相片含有位置資訊。按「所有年份」或某個年份，即可只看那一年。大部分項目都有「顯示這些相片」，地點則有「在地圖上顯示」。

== 旅行地圖

image::travelmap.png[旅行地圖]

「旅行地圖」會為拍過有地理標記相片的國家，以及幅員最大的幾個國家的州與省上色。顏色越深，代表相片越多。

* 可以在「地球儀」與「平面」之間切換。
* 側邊面板會統計「去過的國家」與「大洲」，並顯示「各大洲涵蓋率」。
* 搜尋國家，即可在地圖上找到它。
* 按一下上色的地方會開啟一張資訊卡，按「顯示相片」即可在「地點」中看到那裡的相片。

旅行地圖完全依照相片的 GPS 資訊，所以標記越多相片，上色的地方就越多。它可以離線使用。

== 尋找重複的檔案

側邊欄的「重複的檔案」會找出內容逐位元組完全相同的檔案，即使檔名不同或位於不同資料夾也找得到。搜尋在背景進行，關閉視窗後仍會繼續，側邊欄會顯示已找到幾組。

每組會有一個檔案標示為「保留」：有加星號或編輯過的檔案時，優先保留它。其他副本可以逐一移至垃圾桶，或按「將多餘的副本移至垃圾桶」處理一整組，或按「將所有多餘的副本移至垃圾桶」一次全部處理。「重新搜尋」會再找一次。

== 無法讀取的檔案

掃描時遇到無法讀取的檔案（例如損壞的相片），狀態列會出現一個連結。按一下即可開啟清單，每個檔案都提供「在資料夾中顯示」與「移至垃圾桶」。

== 設定

按一下右上角的齒輪，或按 kbd:[Ctrl+,]，即可開啟「設定」。設定會立即生效。

一般::
語言、色彩主題、縮圖大小、投影片間隔，以及將相片移至垃圾桶前是否先詢問。「更新」可以每天檢查一次有無新版本；有新版本時，右上角會出現它的連結。檢查時只會向 GitHub 查詢最新的版本號碼。

資料夾::
列出 Picasso 監看的資料夾，每個資料夾都有開啟、重新掃描，以及從 Picasso 移除的按鈕。移除資料夾時，檔案仍保留在磁碟上。「排除的資料夾」列出 Picasso 會略過的子資料夾；「排除資料夾…」可以新增，「重新納入」則可恢復。

檔案類型::
決定 Picasso 要加入哪些檔案：JPEG、PNG、GIF、WebP、BMP、TIFF、HEIC／HEIF、相機 RAW 與影片。取消勾選的類型會從圖庫移除，但檔案仍保留在磁碟上。

地圖::
「地點」與地圖面板使用的地圖。預設的「OpenFreeMap Liberty」和「OpenStreetMap」不需要任何設定。「CARTO」有三種風格，需要免費的金鑰：按「取得免費金鑰」會開啟 CARTO 的註冊頁面，再把金鑰貼到欄位中即可。「Esri World Imagery」顯示衛星影像。

GPS 軌跡檔::
軌跡編輯器開啟軌跡時使用的「軌跡整理」設定，按「預設值」可恢復 GPXViewer 的數值。

儲存空間::
圖庫、快取與設定的存放位置與占用空間、「清除快取」，以及備份。

=== 資料夾樹狀圖的右鍵選單

在側邊欄的資料夾上按右鍵，可以選擇：

* Mac 上的「在 Finder 中顯示」、Windows 上的「在檔案總管中顯示」，或 Linux 上的「在資料夾中顯示」，會開啟該資料夾
* 「依 GPS 軌跡標記地點…」
* 「重新命名檔案…」
* 「不要掃描」，出現在不想放進圖庫的子資料夾上
* 「重新掃描這個資料夾」與「從 Picasso 移除…」，出現在你加入的資料夾上

== 圖庫與備份

=== 資料存放在哪裡

圖庫 `picasso.db` 存放你加入的資料夾、每張相片的星號、說明、旋轉、地點、修正過的日期、所屬相簿與編輯，以及你的預設集與 GPS 軌跡。圖庫不包含相片本身，請像備份其他檔案一樣自行備份相片。

快取存放縮圖與地圖圖磚；清除快取很安全，Picasso 會重新產生。你在「設定」中的選擇和最近的搜尋都與圖庫分開，存放在 `settings.json` 中。「設定 → 儲存空間」會顯示各自的位置。

相片旁可能會有兩個小檔案：`.picasso-geotags.json` 存放用「依 GPS 軌跡標記地點…」設定的地點，`.picasso-renames.json` 則存放「重新命名檔案…」之後可用「復原」改回的名稱。

=== 備份

Picasso 每週會在啟動時備份一次圖庫，並保留最新的五份。在「設定 → 儲存空間」中，「立即備份」會馬上備份，「還原…」則會還原一份備份：Picasso 會先備份目前的圖庫，再以你選擇的備份重新啟動。

[#recovery]
=== 圖庫無法開啟時

如果圖庫無法開啟（例如磁碟發生錯誤），Picasso 不會照常啟動，而是說明發生了什麼問題，而且絕不會覆寫圖庫：

* 「再試一次」適用於圖庫只是暫時被占用的情況，例如備份或同步工具正在使用它。
* 「還原 … 的備份」會改用最新一份可讀取的備份。該備份之後的變更將會遺失。
* 「建立新的圖庫」會從你的「圖片」資料夾重新開始。
* 「開啟圖庫資料夾」會顯示這些檔案，「結束」則讓一切維持原狀。

只有在圖庫檔案損壞時，才會提供還原與重新開始。原本的檔案會改名為 `picasso-damaged-` 加上日期，留在新檔案旁邊，不會遺失任何資料。

=== 搬移與重新命名資料夾

Picasso 每次啟動時都會重新掃描資料夾，執行期間也會持續監看；按 kbd:[F5] 可立即重新掃描。

* 在 Picasso 已監看的資料夾之間搬移相片，不必做任何事，下次掃描就會找到它們。
* 若要把整個資料夾搬到新位置，請先搬移，再到「設定 → 資料夾」移除舊位置，然後按「+  匯入」加入新位置。Picasso 會認出這些相片，並恢復它們的星號、說明、相簿與編輯。
* 位於未連接磁碟機上的資料夾，會保留其中的相片，直到磁碟機接回來為止。

相片離開圖庫後，它的星號、說明、相簿與編輯會保留 90 天，以備它再回來。

== 疑難排解

影片沒有出現或無法播放::
請安裝 FFmpeg（見 <<ffmpeg>>），再重新啟動 Picasso。FFmpeg 缺少時找到的影片，屆時就會加入。

地圖一片空白::
地圖需要連上網路。如果你選了「CARTO」，請確認已在「設定 → 地圖」中輸入金鑰，或改用「OpenFreeMap Liberty」。

找不到某張相片::
請確認它的資料夾列在「設定 → 資料夾」中、不在「排除的資料夾」裡，且它的類型已在「設定 → 檔案類型」中勾選。按 kbd:[F5] 重新掃描，並查看狀態列中無法讀取的檔案。

Mac 顯示無法打開 Picasso::
請見 <<install>>：到「系統設定 → 隱私權與安全性」按一下「強制打開」。

AppImage 無法啟動::
在沒有 FUSE 的環境（例如容器）中，請加上 `--appimage-extract-and-run` 執行。

Picasso 顯示圖庫無法開啟::
請見 <<recovery>>。
